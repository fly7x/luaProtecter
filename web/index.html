FAQ

Why did I get “Missing or empty code field”?

The old server read one network packet and dropped the JSON body. That parser is replaced. Redeploy this build before testing again.

Will this run in Roblox?

The emitted file is Luau. It uses bit32, _ENV, and table.unpack only. No getfenv, no os, no debug.

Is this Luraph-level?

No. This is a working custom VM pipeline. Strength comes after the output actually executes.

Free vs premium?

Not enforced yet. The cards are placeholders until the VM is stable.
