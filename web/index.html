Luau protection, self-hosted

Ship scripts nobody can read.

fly::protect() compiles your Luau source onto a private instruction set and runs it through a generated interpreter. Every build gets its own opcode map, so no two outputs are the same file.

What happens on protect

Four stages run in order, every time. None of them are optional and none of them are decoration.

01

Virtualize

Source is compiled, remapped onto a private instruction set, then executed by an interpreter generated for that build.

02

Mutate

The opcode map, local names, and dispatch keys change per build, so two protected files never share a byte-for-byte structure.

03

Lock constants

Strings and numbers leave the blob encoded. The VM reconstructs each one only at the moment it's needed.

04

Integrity

A payload checksum and a small anti-debug probe run before the dispatch loop starts.
