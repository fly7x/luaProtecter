What happens on protect

Four stages, every time

None of these are optional and none are decoration — every script that goes through FŁY passes through all four, in order.

01

Virtualize

Your script is compiled and remapped onto a private instruction set, then run by an interpreter generated specifically for that build.

02

Mutate

The opcode map, local names, and dispatch keys change on every build, so two protected files never share a byte-for-byte structure.

03

Lock constants

Strings and numbers leave the output encoded. The VM reconstructs each one only at the moment it's actually needed.

04

Integrity

A payload check and a small anti-debug probe run before the dispatch loop starts, ahead of your script's own code.
