How to use it

  1. Open /obfuscator.
  2. Paste Luau. Start with print("hi") if you just want to see it work.
  3. Click Protect, copy the output, and put it in a Script or LocalScript.
  4. Don't wrap the output in another obfuscator until this one is stable for you.
// what it emits

A plain Luau file. No native binaries. Uses bit32, string, table, and a VM generated for that build. Compatible with Roblox and with Run on luau.org.

// honesty

No public VM is undecompilable. fly::protect() raises time-to-recover, not the difficulty to zero. It isn't Luraph and won't become Luraph by stacking fake layer counts.

fly::protect() — custom VM pipeline for Luau Questions belong in the repo, not a support queue.
