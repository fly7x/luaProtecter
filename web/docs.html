How to use it

  1. Open /obfuscator.
  2. Paste Luau. Start with print("hi").
  3. Protect, copy the output, put it in a Script or LocalScript.
  4. Do not wrap the output in another obfuscator until this one is stable.

What it emits

A Luau file. No native binaries. Uses bit32, string, table, and a generated VM. Compatible with Roblox and luau.org Run.
