# luaProtecter

Small C++ project skeleton for a Lua "protector"/obfuscator tool.

This repository contains a minimal project layout with stubs for a lexer, transformer, emitter, and obfuscation components. It also includes a sample input Lua script and a placeholder for the protected output.

Usage

- Build: mkdir build && cd build && cmake .. && cmake --build .
- Run (after implementation): ./luaProtecter
